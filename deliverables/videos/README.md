# Sprint outcome videos

Put the two videos here, with these names:

| File | Length | What it shows |
|:--|:--|:--|
| `sprint-1-outcome.mp4` | about 1 minute | Sprint 1 working product: register and sign in, add an expense with a receipt, categories, a budget with its utilisation |
| `sprint-2-outcome.mp4` | about 2 minutes | Sprint 2 working product: recurring expenses, CSV import, shared budgets, alerts, analytics and forecast, PDF/Excel reports, audit history, backups |

Start the app with `bash deploy/local-demo.sh` (https://localhost) and record the screen. GitHub accepts files up to
100 MB; keep each video under that (720p is plenty).
